# Identidad visual de Novillo

La interfaz utiliza el logo proporcionado por el restaurante, ubicado en `public/logo-novillo.png`. La paleta se inspira en el toro negro y el atardecer rojo y ámbar. Los colores más vivos se reservan para acciones y estados; las superficies de trabajo mantienen contraste y permiten leer tablas durante turnos largos.

| Uso | Color | Valor |
| --- | --- | --- |
| Navegación y caja del cliente | Carbón | `#151310` |
| Texto principal | Tinta | `#24211E` |
| Fondo de trabajo | Marfil | `#F7F5F1` |
| Tarjetas y formularios | Blanco cálido | `#FFFEFD` |
| Acción principal | Rojo Novillo | `#C93523` |
| Acción principal al pasar el cursor | Rojo profundo | `#A82A1B` |
| Foco y detalles | Ámbar | `#F2A51F` |
| Texto secundario | Gris cálido | `#77736D` |
| Divisores | Piedra clara | `#E8E3DD` |

**Tipografía:** Manrope para navegación, formularios, tablas y cifras; DM Serif Display para el titular editorial de la página pública. La jerarquía usa títulos fuertes, descripciones breves, pestañas de contenido y una acción principal por vista.

**Patrón de interacción:** cada panel administrativo abre en una lista. Las pestañas separan tipos de registros. “Agregar” o “Registrar” abre un formulario enfocado y “Volver a la lista” lo cierra. Las filas editables muestran una acción contextual. Los valores y permisos existentes se conservan.
