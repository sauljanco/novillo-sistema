# Prototipo local Python

Requiere Python 3.10 o superior. Ejecutar `python app.py` y abrir `http://localhost:8000` para el operador y `http://localhost:8000/cliente` para la segunda pantalla en el mismo equipo. Ejecutar `python test_app.py` para la prueba integral.

La base de datos `novillo.sqlite3` se crea al iniciar y carga `menu-inicial.csv`. Es una prueba de flujo, sin usuarios ni permisos. No usar con dinero real. El QR se marca manualmente, no se verifica contra un banco. La ficha no es una factura fiscal.
