# Novillo

Sistema de gestión para el restaurante Novillo (Sacaba, Cochabamba).

- [Alcance y reglas del negocio](ALCANCE-NOVILLO.md)
- [Arquitectura React + Neon + Vercel](STACK.md)
- [Menú inicial transcrito](menu-inicial.csv)
- [Prototipo local Python/SQLite](PROTOTIPO.md)

La aplicación de producción se construirá en React + TypeScript + Vite, con Neon Postgres, Better Auth y Vercel. El proyecto Neon ya existe, pero su ubicación en la organización gratuita está pendiente de autorización. El prototipo local sirve para validar atención, segunda pantalla, caja y personal durante la migración.
