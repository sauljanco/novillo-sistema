# Novillo

Sistema de gestión para el restaurante Novillo (Sacaba, Cochabamba).

- [Alcance y reglas del negocio](ALCANCE-NOVILLO.md)
- [Arquitectura React + Neon + Vercel](STACK.md)
- [Menú inicial transcrito](menu-inicial.csv)
- [Prototipo local Python/SQLite](PROTOTIPO.md)

La aplicación de producción se construirá en React + TypeScript + Vite, con Neon Postgres, Better Auth y Vercel. El proyecto Neon de trabajo ya está en la organización gratuita Novillo Desarrollo. Hay un duplicado vacío en Launch pendiente de eliminación. El prototipo local sirve para validar atención, segunda pantalla, caja y personal durante la migración.
